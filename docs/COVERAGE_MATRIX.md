## 現時点の境界

- 全47都道府県に最低1候補はある。
- 全国11地域すべてに、詳細・料金・運用を比較できる施設が最低1件ある。
- 58候補のうち、詳細未観測12施設、料金未観測14施設、運用未観測12施設が残る。
- 「料金あり」は総費用見積ではない。施設基本料、冷暖房、清掃、警備、回線、舞台、電気等を条件付き観測として分離し、未確認費を0円にはしていない。
- 施設単位の値を跨いで誤結合しないため、Web検索では面積・収容・天井・舞台・基本料を同じ貸出区画で照合できる。

## 次に密度を上げる場所

1. 四国は4候補すべてに詳細・料金・運用の比較起点ができた。次は料金区分と回線・警備・清掃の不足を補う。
2. 九州は8候補すべてに詳細・運用観測ができた一方、料金は6施設に留まる。出島メッセ長崎とシーガイアの料金条件を確認する。
3. 北陸は3候補中2施設まで比較可能になったため、フェニックス・プラザを補う。
4. 中国は5候補中4施設まで比較可能になったため、広島県立広島産業会館を補う。
5. 詳細未観測の各県代表候補へ、面積・天井・収容・舞台・練習利用の最低項目を付ける。

この優先順位は調査密度を均すための案であり、施設の優劣や開催可否を示すものではありません。
