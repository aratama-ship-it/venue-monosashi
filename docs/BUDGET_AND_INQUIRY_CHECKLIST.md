# 会場予算・問い合わせチェックリスト

状態: 検索MVPから見積シナリオへ進むための設計案  
用途: 候補比較、施設への問い合わせ準備、見積回答の記録

## 1. 先に固定する催事条件

- イベント名と種別
- 本番日数
- 設営日数・時間
- 撤去日数・時間
- 曜日、祝日、深夜・早朝の有無
- 営利／非営利
- 入場料の有無と最高額
- 参加者、観客、出演者、スタッフの各人数
- 平土間、固定席、舞台、練習区画、控室、物販、配信の必要数
- 同時利用する区画と時間帯

同じ施設でも、曜日、入場料、利用目的、準備・本番、全面・分割で料金が変わるため、ここが未確定なら総額を1本にしない。

## 2. 施設へ確認する費目

| 費目 | 確認する内容 | 現データの扱い |
|---|---|---|
| 施設基本料 | 区画、日数、時間帯、曜日、営利、入場料区分 | 44施設で観測あり |
| 設営・撤去 | 準備料金、延長、深夜、連続利用、原状復帰 | 条件付き観測のみ |
| 冷暖房・換気 | 必須時間、時間単価、最低利用時間 | 一部施設のみ |
| 電気・水道・ガス | 従量、容量、持込機器、幹線工事 | 一部施設のみ |
| 舞台 | 常設、仮設、サイズ、設営撤去、舞台人件費 | 設備料金の一部のみ |
| 音響・照明・映像 | 基本設備、追加機材、オペレーター、持込料 | 一部施設のみ |
| 通信・配信 | 専用回線、帯域、固定IP、工事、持込回線 | 独立料金観測は5施設 |
| 清掃・廃棄物 | 必須清掃、床面積単価、ごみ処理、分別 | 独立料金観測は5施設 |
| 警備・救護 | 必要人数、配置時間、指定事業者、救護室 | 独立料金観測なし |
| 駐車・搬入 | 主催者車両、大型車、留置、搬入口、誘導員 | 運用観測と分離 |
| 備品 | 机、椅子、柵、床養生、控室、ロッカー | 一部施設のみ |
| 消防・行政 | 届出、避難要員、裸火、物販、食品、酒類 | 料金外の条件 |
| 税・サービス料 | 税込／税別、サービス料、改定日 | 観測行ごとに保持 |
| キャンセル | 申込金、支払期日、取消料、日程変更 | 総額とは別管理 |

「独立料金観測なし」は無料を意味しない。公開料金表にない場合は`要問い合わせ`として残す。

## 3. 施設適合の確認項目

### 空間

- 有効面積と柱・段差・死角
- 最低天井高と吊物可能高
- 床荷重、床材、養生条件
- 舞台寸法、袖、搬入経路
- 固定席、可動席、仮設席の実収容
- 練習区画と本番区画を同時利用できるか
- 控室、審査室、運営本部、救護室の数

### 運営

- 最寄駅・空港からの実移動
- 一般、出演者、搬入、VIP、救護の動線分離
- 大型車の寸法・重量制限と待機場所
- 予約開始、仮押さえ、本申込、支払時期
- 連続利用、夜間留置、鍵・警備の扱い
- 物販、飲食、キッチンカー、酒類の可否
- 音量、振動、スモーク、裸火、飛翔物の制限
- バリアフリー席、補助犬、字幕・手話対応
- Wi-Fiではなく配信に必要な上り帯域と専用性
- 周辺宿泊、終演後交通、スタッフ早朝移動

### ジャグリング・ヨーヨー固有

- 高投げ、長いひも、オフストリング、ディアボロ等の安全範囲
- 照明器具・天井設備・客席との離隔
- 道具落下による床傷への養生条件
- 競技音源の再生、持込PC、バックアップ系統
- 練習場の音出し、深夜利用、同時収容
- 観客と選手の交差を避ける待機導線
- ライブ配信、審査席、計時、結果表示の電源・回線

## 4. 検索画面での予算表示

現MVPの「確認済み日額」は、`施設基本料 × 1日`の比較起点であって総費用ではない。時間区分しかない施設については、同一区画・同一適用期間の確認済み区分だけを足した参考合計11件を別表に保持し、利用者が明示的に有効化したときだけ検索へ含める。どちらも次の総額項目とは分けて表示する。

1. 確認済み基本料
2. 確認済み時間区分から組み立てた参考合計
3. 条件を選ぶと算定できる追加費
4. 必須だが金額未確認の費目
5. 施設外費用（交通、宿泊、輸送、保険、人件費）
6. 予備費

総額を出す条件は、選択区画、日程、利用目的、税込条件が一致し、必須費が確認済みであること。条件の異なる観測を自動で足さない。

## 5. 回答を記録するとき

- 回答日
- 回答元部署・担当窓口
- 対象日程・区画・用途
- 公開料金表と個別見積の区別
- 有効期限
- 税・除外費
- 予約可否と空き状況
- 公開可否・個人情報の扱い

施設からの個別回答は、公開一次情報と同じ表へ上書きせず、将来の問い合わせ観測履歴として分離する。
