# 会場ものさし 検索モデル案

状態: 初期検索MVP実装済み・詳細判定は設計中  
事実データ: `data/*.csv`の`verified`行  
提案: 本文の検索順・表示方法・プリセット

## 1. 「何人入るか」だけで探さない

会場ものさしは、候補を単一の総合点で順位付けしない。次の4本のものさしを並べ、利用者が「何が似ていて、何が不足し、何を問い合わせるべきか」を判断できるようにする。

1. **規模ものさし**: 参加者、観客、競技者、スタッフ、固定席、平土間時収容。
2. **空間ものさし**: 平土間面積、天井高、舞台、練習と本番の同時進行、控室、会議室。
3. **運営ものさし**: 駅・空港、搬入、予約開始、連続日程、設営撤去、物販、飲食、配信。
4. **予算ものさし**: 会場基本料、冷暖房、設備、電気水道、設営、警備、清掃、仮設舞台、通信。

過去大会は「おすすめ会場」ではなく、条件の組合せを理解するための実例として表示する。

## 2. 検索の入口

### 過去大会から測る

- 「JJF 2024（アクリエひめじ）に近い」
- 「JYYF全国大会の横浜市教育会館型」
- 「WYYC 2023（大阪国際交流センター）程度」
- 「JJF 2020のような複数小会場＋オンライン」

選択した大会の施設構成、都市、空間数、確認済み設備を入力の初期値にする。参加人数や予算を過去大会から推測して自動入力せず、出典がある値だけを表示する。

### 条件から測る

- 都道府県・地方・交通圏
- 参加者、観客、スタッフの各人数
- 平土間、固定席、舞台、練習室、控室の必要数
- 最低天井高、最低面積
- 連続日数、設営日、撤去日
- 物販、飲食、配信、大型搬入
- 会場基本料上限と総予算上限

### 会場の大きさから測る

- 地域大会・発表会
- 全国大会・フェスティバル
- 国際大会・複数日程
- メッセ・展示会・1万人規模

この名称は検索プリセットであり、収容人数の事実値ではない。初期値はユーザーが確認・変更できるようにする。

## 3. 判定ロジック

### 必須条件を先に判定

- `条件一致`: 公式公開値で条件を満たす。
- `要問い合わせ`: 施設側の公開値がない、または催事内容によって変わる。
- `条件外`: 公式公開値で条件を満たさない。
- `未調査`: まだ一次情報を取得していない。

不明値を0、不可、不合格として扱わない。`要問い合わせ`と`条件外`は必ず分ける。

### 比較は差分を見せる

候補カードには、総合点より先に次を表示する。

- 基準大会と共通する条件
- 基準大会より大きい／小さい項目
- 追加で必要な別会場、仮設舞台、移動
- 公式情報で確認できない項目
- 問い合わせ時に聞くべき質問

同点の候補を無理に順位付けせず、交通、予算、運営負荷など利用者が選んだ優先軸で並べ替える。

## 4. 予算表示

### 算定する値

`確認済み最低額 = 選択した時間帯の施設基本料 + 必須と判明している追加料金`

追加料金は、冷暖房、設備、電気水道、設営、清掃、警備、仮設舞台、回線を別行で積み上げる。同じ料金表でも、平日・休日、営利・非営利、入場料、全面・分割、準備・本番を混ぜない。

### 算定しない場合

必須費用が未確認なら「総額」を出さない。代わりに次を表示する。

- 確認済み最低額
- 未確認の必須費用
- 料金表の調査日
- 税込・税別
- 想定した曜日、時間、利用目的

利用者の旅費・宿泊・輸送・保険・人件費は施設料金と分け、将来の「参加者負担ものさし」で扱う。

## 5. 結果カードの情報順

1. 施設名、都市、確認状態、調査日
2. 「この条件なら使う区画」の組合せ
3. 必須条件の一致・問い合わせ・条件外
4. 確認済み最低額と未確認費用
5. 基準大会との共通点・差分
6. 駅、空港、搬入、予約開始、連続日程
7. 公式出典

施設全体の最大値ではなく、検索条件に実際に使う貸出区画の値を表示する。複合施設や隣接2施設は「会場セット」としてまとめる。

## 6. 初期実装の優先順位

1. 公式値のある面積、天井、収容、基本料、冷暖房、駅アクセスで絞り込む。
2. `条件一致 / 要問い合わせ / 条件外 / 未調査`を理由付きで表示する。
3. JJF、JYYF全国・地区・ジュニア、WYYCの過去大会を基準として呼び出せるようにする。
4. 会場基本料と追加費を分離して比較する。
5. 施設への問い合わせ結果は、公開情報とは別の観測履歴として保存する。

空き状況、見積額、宿泊価格は変動情報なので、この調査版の静的データとは別の更新周期・確認日時を持たせる。

## 7. ローカルMVPで実装した範囲

`web/`では、全国58候補を対象に次を実装した。

- JJF型、国内ヨーヨー大会型、世界大会型の仮プリセット
- 11地域と連動する都道府県、キーワード、最低面積・収容人数・天井高・駐車台数
- 固定舞台、練習利用、大型車搬入、駅・空港・予約・通信情報の有無
- 確認済み1日施設基本料の上限
- アマチュアスポーツ、展示・イベント、入場料なし・非営利、入場料ありの料金用途
- 面積・収容・天井・舞台条件と基本料を同じ貸出区画へ限定する切替
- 証拠量、基本料、収容、面積、予約開始時期による並べ替え
- 未確認値を「要問い合わせ」として候補に残す切替
- 区画値・料金値の観測有無、未確認付帯費、適用日・税・除外費、駅・空港・駐車・搬入・通信、公式情報リンク
- 過去大会199記録の系列、年、会場名・都市検索と、開催・確認状態、一次情報リンク
- 表記揺れ辞書で照合した過去大会実績の候補カード表示と「実績あり」絞り込み

現段階のプリセット数値は検索操作を試すための提案値であり、確定仕様ではない。予算上限は総額ではなく、`charge_category=facility`かつ`unit=per_day`の確認済み最小観測値に適用する。通常表示では複合施設内の別区画を含む候補内最小額であることを明記し、「同じ貸出区画で満たす」選択時は数値条件に一致する`space_id`の料金だけを使う。料金用途を選んだ場合は、その用途または用途共通の観測だけを日額比較へ使う。イベントプリセットから法的・料金上の用途区分を推測して自動選択はしない。

施設が一括日額を公表せず時間区分だけを示す場合は、`budget-scenarios.csv`に同じ区画・用途・適用期間の確認済み区分と数量を列挙し、監査で合計を再計算する。これは公式一括日額ではないため既定の予算検索には入れず、利用者が「区分料金から組み立てた参考合計も予算検索に含める」を選んだときだけ候補値へ加える。準備・撤去区分、異なる用途・曜日・適用日の料金は自動合算しない。
