# 会場ものさし Web検索MVP

全国候補、施設内区画、料金観測、運用観測を、過去大会由来の条件で絞り込むWeb版です。

## 検索できること

- JJF型、国内ヨーヨー大会型、世界大会型、ディアボロ型、けん玉大会型、小劇場型のプリセット
- 都道府県、キーワード、最低・最大収容人数、最低天井高
- 小劇場・ブラックボックスの会場タイプ
- 確認済み施設基本料の上限
- 数値が未公開の施設を「要問い合わせ」として候補に残すか
- 検索条件を含む共有URLと最大3施設の比較
- モバイル用の開閉式絞り込みと先頭40施設表示
- 一次情報の観測日、公開版更新日、更新履歴、訂正提案導線
- 公式情報へのリンク

検索結果の基本料は総額見積ではありません。冷暖房、警備、清掃、設営撤去、設備、人件費等は、観測できたものだけを別料金として原本データに保持しています。

## デザインコンセプト

2026-07-30版は、株式会社ベイジの採用サイトに見られる固定サイドナビ、大きな主役パネル、白・黒・蛍光黄の明快な情報階層を参照しています。写真や固有表現は模倣せず、会場ものさし固有の「採寸図」「目盛り」「根拠カード」へ置き換えています。

- PC: 左にページ案内、右に検索と比較のキャンバス
- モバイル: 案内を横スクロールできる固定ヘッダーへ変換
- 実在会場と誤認する架空写真を使わず、CSSの抽象的な平面図を主役にする
- 収録数、未確認値、一次情報リンクを装飾より優先する

## データ更新

`../data/*.csv`が原本です。開発・ビルド前に`scripts/generate-data.mjs`が読み込み、`app/generated-data.ts`を再生成します。

```bash
npm run data:generate
npm run dev
npm run build
node --test tests/rendered-html.test.mjs
```
